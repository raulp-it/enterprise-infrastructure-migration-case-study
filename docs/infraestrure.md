# Infrastructure

## Internet Edge

The infrastructure included public DNS services, Internet service providers,
public-facing services and datacenter connectivity.

## Identity

The environment included on-premises Active Directory integrated with
Azure Active Directory through Azure AD Connect.

## Cloud Services

Microsoft 365 services included:

- Office 365
- Microsoft Teams
- SharePoint
- OneDrive for Business

## On-Premises

The on-premises environment included Windows Server and Linux systems,
database servers, file servers, application servers and legacy workloads.

## Branch Connectivity

Branch offices were connected to the headquarters through VPN-based
connectivity.

## Development

Internal software development infrastructure included Bitbucket, GitLab
and Jira.
